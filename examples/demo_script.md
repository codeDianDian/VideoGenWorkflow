# 30 秒讲清楚：什么是「Computer Use」

很多人以为 AI 只能在聊天框里给你建议，
但「Computer Use」能让模型像人一样真的去操作电脑。

它能做三件事：
1. **看屏幕**：截图给模型，模型识别 UI 元素。
2. **动鼠标键盘**：根据任务规划点击 / 输入 / 滚动。
3. **闭环验证**：执行后再次截图，确认结果是否符合预期。

举个例子：你说「帮我在 Notion 里建一个本周 OKR 模板」，
它会真的打开浏览器，登录，新建页面，挨个填字段，最后把链接给你。

为什么是现在？因为多模态模型已经能稳定理解 UI，
配合任务规划，它从「会聊」变成了「会做」。

下一步该试什么？
把你最重复的一项操作，写成一段 prompt，让 Computer Use 跑一次看看。
